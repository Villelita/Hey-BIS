# Hey BIS — sonidos de ambiente

Este directorio contiene 2,000 clips del dataset ESC-50 de Karol J. Piczak en dos formatos WAV mono PCM de 16 bits.

- `audio/esc50/` contiene los archivos originales a 44.1 kHz.
- `audio/esc50/pcm16k/` contiene las copias remuestreadas a 16 kHz para Hey BIS. `manifest.csv` registra estas copias como `background` y conserva sus particiones.
- `sources/esc50/` y `sources/preparation/` contienen los metadatos originales, la procedencia, las atribuciones y el registro de la conversión.

Fuente: <https://github.com/karolpiczak/ESC-50>. El conjunto ESC-50 se distribuye bajo CC BY-NC 3.0. El subconjunto ESC-10 está disponible bajo CC BY 3.0. Consulta [la licencia y los créditos individuales](sources/esc50/LICENSE).
